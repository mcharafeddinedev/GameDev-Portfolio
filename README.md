### Quantum Tether — Unity (Texas Game Jam 2025, EGaDs @ UT Austin)
Endless roguelike sidescroller made in a weekend: swing on stars and asteroids with mouse grappling—left-click main grapple, right-click second rope (unlockable), Space shortens rope, Shift dashes toward cursor. Inspired by *Spider-Man: City Raid*.

**Links:** [Itch.io](https://goldleafinteractive.itch.io/quantum-tether) | [Documentation](Docs/QuantumTether/)

**Technical Highlights**
- **Grapple feel** — Connects where you point; damping and rope length tuned for arcade swing, not floppy chaos; dash assists repositioning
- **Procedural levels (PCG)** — No fixed map; layers hand-authored pieces (safe anchors, danger pockets with corrupted red anchors, pickups) selected by weighted rules as run speeds up
- **Difficulty tiers** — Controlled escalation instead of pure RNG; pattern difficulty rises predictably
- **Roguelike systems** — 10+ upgrades that change movement/interaction; normal vs corrupted anchors; full HUD and score flow; fresh start as next "clock spirit" on wipe
- **Event-based architecture** — Decoupled gameplay systems with `DistanceJoint2D` and `LineRenderer` grappling

### BREATHE Arcade — Breath-Controlled Minigame Collection (Unity)
A collection of breath-controlled minigames where breath is the only input. Built around custom hardware (fan-based breath sensor with Arduino) or microphone fallback. Five playable minigames, each targeting different breathing patterns—no one ever loses.

**Links:** [Itch.io](https://goldleafinteractive.itch.io/breathe-arcade) | [Documentation](Docs/Breathe/) | [Project repository](https://github.com/mcharafeddinedev/Breathe-Game)

**Minigames**
- **Sailboat** — Fill the sails with steady breath to win a race against AI companions
- **Balloon** — Long, controlled exhales inflate balloons faster
- **Bubbles** — Chain bubbles with a consistent stream of breath
- **Stargaze** — Breathe to push clouds and reveal constellations
- **Skydive** — Guide a parachuting skydiver by breathing to fire jetpack thrusters

**Technical Highlights**
- **IMinigame interface** — Shared lifecycle, analytics, session logging, and result display across all games
- **Source-agnostic breath pipeline** — Signal capture → normalization → EMA smoothing → dead zone → gameplay; one interface regardless of hardware, microphone, or simulated source
- **Custom hardware integration** — Developer-built breath-reactive device (DC motor/propeller generates voltage proportional to breath effort, read via Arduino over USB serial)
- **Spin-down compensation** — Detects fan coast after player stops blowing and snaps to zero rather than trailing off
- **Procedural generation** — Scenes are minimal; ocean surface, race courses, obstacles, backgrounds, and UI overlays are generated at runtime
- **No-fail design** — Every session ends with celebration of personal progress; AI rubber-banding and soft time caps guarantee positive outcomes
- **Breath analytics** — Captures intensity, duration, patterns, and personal bests per minigame

**Tech:** Unity 6 (C#), 2D URP, Windows PC + WebGL. Input abstraction allows swapping custom device / microphone fallback / simulated input without changing gameplay code.

### ACCESS GRANTED — Unity 6 (The Movie The Game The Jam 2026)
A *Hackers* (1995)-inspired arcade game: classic brick breaker action plus typing challenges when you hit special command blocks. Neon terminal aesthetics, CRT-style presentation, short score-chasing sessions.

**Links:** [Itch.io](https://goldleafinteractive.itch.io/access-granted)

**Technical Highlights**
- **Dual-mode gameplay** — Paddle/ball reflexes switch to typing precision when command blocks are hit
- **Modular block types** — Standard, heavy, command, indestructible, explosive blocks with HP tiers
- **Typing subsystem** — World-space falling prompts with slow-mo, max overlap rules, and paddle freeze during input
- **Rule-of-three failure** — Separate ball-miss and typing-fail strike bars; game over when either hits limit
- **Power-up system** — Wide paddle, slow ball, and score burst pickups
- **WebGL-first** — Auto-pause on tab blur, audio ducking during typing mode

**Tech:** Unity 6 (C#), 2D physics, WebGL + Windows builds.

### Dread & Breakfast — Unity 6 (Mini Jam 208: Inverted)
A cozy-spooky top-down haunting strategy game where the roles are reversed—you are the ghost, and the humans are the problem. Scare visitors until they flee before dawn.

**Links:** [Itch.io](https://goldleafinteractive.itch.io/dread-and-breakfast)

- **Loose coupling** — GameEvents pattern lets UI, audio, and progression react without tight subsystem coupling

**Tech:** Unity 6 (C#), 2D orthographic, WebGL + Windows builds.

### Trenchglow — Unity (Mini Jam 209: Deep)
A 2D deep-sea adventure where you play as a treasure-hunter trapped in abyssal trenches. Most of the world is hidden in darkness—sonar pulses reveal the environment momentarily.

**Links:** [Itch.io](https://goldleafinteractive.itch.io/trenchglow)

**Technical Highlights**
- **Sonar reveal system** — Dual tilemap visibility (resolved vs scan silhouette) with shader globals and darkness overlay
- **Stamina-gated swimming** — Upward swim costs stamina, boost provides one-shot kicks, lateral swim has buoyancy
- **Puzzle infrastructure** — PressurePoints, TrenchChunks (kinematic moving geometry), Doors, and StateChannel boolean buses for combinational logic
- **Permadeath-style progression** — Death reloads chapter's first scene; checkpoints exist but are no-op for the jam model
- **App state machine** — GameSession owns GameState (Boot, Menu, Loading, Playing, Paused, Dying) and input routing
- **Responsive UI** — MainMenuResponsiveLayout re-anchors elements for WebGL iframes, ultrawide, and narrow widths

**Tech:** Unity (C#), 2D URP, Input System package, WebGL + Windows builds.

## Code Example — OVERCLOCK System (Unreal / C++)

```cpp
void UOverclockSystemComponent::ActivateOverclock()
{
    if (bIsOverclockActive) return;
    
    bIsOverclockActive = true;

    // Apply speed multiplier to world scroll
    if (WorldScrollComponent)
    {
        WorldScrollComponent->SetOverclockMultiplier(SpeedMultiplier, true);
    }

    // Activate bonus scoring
    if (ScoreSystemComponent)
    {
        ScoreSystemComponent->SetOverclockActive(true);
    }

    // Trigger camera zoom for intensity
    if (AStateRunner_ArcadeCharacter* Character = GetPlayerCharacter())
    {
        Character->SetOverclockZoom(true);
    }

    // Audio feedback
    PlayOverclockSound(OverclockActivateSound);
    StartOverclockLoop();

    OnOverclockStateChanged.Broadcast(true);
}
```
